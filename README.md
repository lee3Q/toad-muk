# 🐸 털두꺼비의 묵 사냥: 광란 모드 (Toad Muk: Berserk Edition)

> **지리산 털두꺼비의 쫀득쫀득 도토리묵 먹방 아케이드 서바이벌 웹게임!**  
> 외부 라이브러리/이미지/오디오 파일 일절 없는 **100% 바닐라 HTML5 Canvas + Web Audio API** 기반 초경량 단일 파일 게임입니다.

🎮 **지금 바로 플레이하기**: [https://lee3q.github.io/toad-muk/](https://lee3q.github.io/toad-muk/)

---

## 🕹️ 조작법 (모바일 한 손 완벽 지원)

* **🕹️ 가상 조이스틱 (하단 좌측)**:
  * **좌우 이동**: 엄지로 부드럽게 아날로그 조향.
  * **점프**: 조이스틱을 **위로 튕기듯이 밀면 즉시 점프** (한 손으로 이동+점프 동시 제어!).
* **👆 화면 터치**: 터치한 위치로 혓바닥 초고속 발사 (주변 아이템 자동 조준 보정).
* **💨 대시 버튼 (우측 하단)**: 0.3초간 보라색 잔상을 남기며 돌진하는 **무적 회피기**.
* **⌨️ PC 키보드 지원**: `A`/`D` 또는 `←`/`→` 이동, `W` 또는 `↑` 점프, `Space` 혓바닥, `Shift` 대시.

## 🔥 핵심 시스템 & 재미 요소

### 1. 일반 모드 vs 광란 모드 (BERSERK FRENZY)
* **일반 모드**: 떨어지는 도토리묵을 먹어 광란 게이지를 100%까지 모으는 빌드업 구간.
* **🔥 광란 모드 (9초간)**:
  * 화면이 붉은 네온 사이버펑크로 전환되며 **5갈래 기관총 혓바닥**이 전장의 묵을 쓸어담음!
  * **장애물 폭증**: 고속 가시탄과 낙뢰가 쏟아져 **앞뒤/좌우로 무조건 칼회피**해야 함. (피하면서 쓸어담는 극한의 쾌감!)

### 2. ⚡ 저스트 닷지 (Near-Miss 불릿 타임)
* 가시돌이 두꺼비 몸체를 스치듯 아슬아슬하게 지나갈 때 **0.35초간 시간 왜곡 슬로우모션** 발동!
* 충격파와 함께 **광란 게이지 대량 충전(+18%)**으로 위기를 기회로 역전.

### 3. 특수 묵 & 기믹
* 🟤 **도토리묵**: 기본 점수 + 콤보 상승.
* 🌟 **황금묵**: 대량 점수 + 광란 게이지 26% 급속 충전.
* ❄️ **얼음묵 (희귀)**: 위기 탈출용 4.5초 불릿타임 슬로우 모션.
* 💣 **폭탄묵**: 전장의 모든 장애물을 일격에 날려버리는 메가 붐 연쇄 폭발!
* 🟣 **독묵**: 3.5초간 이동속도 50% 감속 디버프.
* ⚡ **천벌 낙뢰**: 상공의 붉은 레이저 예고선 깜빡임 후 수직 강타.

## 🛠️ 기술적 특징

* **Zero Dependencies**: 외부 CDN, 이미지 파일, 오디오 라이브러리 의존성 0%.
* **Web Audio Synthesizer**: 점프, 타격 킥, 혓바닥 채찍, 레트로 8비트 BGM 전체를 브라우저 내장 오디오 오실레이터로 실시간 합성.
* **PWA & 모바일 최적화**: 풀스크린 터치 제어(`touch-action: none`) 및 고주사율 Canvas 렌더링.
