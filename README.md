# 털두꺼비의 묵 사냥

스마트폰을 좌우로 기울여 두꺼비를 피하고, 화면을 눌러 묵을 낚아채는 짧은 아케이드 게임입니다.

**플레이:** https://lee3q.github.io/toad-muk/

## 조작

- 스마트폰: 기울이기 또는 화면 드래그로 좌우 이동
- 화면 탭: 탭한 위치의 묵·파리로 혓바닥 스냅
- PC: 마우스 클릭, `A`/`D`, `←`/`→`

## 이번 플레이 개선

- 광란을 7초로 줄이고, 3갈래 혓바닥 volley에 충전 수를 도입했습니다. 혀가 돌아오는 동안에는 다시 발사할 수 없습니다.
- 가시돌은 일반·광란 어느 때도 혓바닥으로 튕겨낼 수 없습니다. 가까이 스치면 저스트 닷지 보너스, 부딪히면 생명 감소입니다.
- 광란 중 묵·황금묵·가시돌이 함께 등장하도록 조정해 조준과 회피를 동시에 요구합니다.
- 묵을 놓치면 콤보가 끊기고, 광란 게이지는 잠시 행동하지 않으면 서서히 식습니다.
- 과한 네온·대문자·이모지 중심 화면을 줄이고, 연못과 수초를 연상시키는 따뜻한 야간 색상과 단순한 도형 그래픽으로 정리했습니다.
- 재시작할 때 이전 판의 생성·낙뢰 타이머와 입력 상태가 남지 않도록 초기화했습니다.
- 기울기 입력이 켜진 기기에서도 드래그를 잠시 우선할 수 있어, 권한이 없거나 기울이기 어려운 환경에서도 바로 플레이할 수 있습니다.
- 첫 판에는 핵심 조작 힌트를 잠시 표시하고, 게임오버 화면에는 최대 콤보·저스트 회피·포획 수를 보여줍니다.
- 첫 화면은 묵 포획과 가시돌 회피라는 핵심 판단을 먼저 안내하며, 인트로 문장이 작은 화면에서도 깨지지 않습니다.
- 가시돌은 실제 충돌할 때 생명을 잃고, 충돌하지 않은 근접 통과만 저스트 회피로 인정됩니다.
